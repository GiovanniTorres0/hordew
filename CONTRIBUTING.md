# Como colaborar com o Hordew

1. **Ideia ou bug?** Abra uma [Issue](https://github.com/GiovanniTorres0/hordew/issues/new) explicando o que você quer (ex.: "o Hunter está forte demais", "ideia: torre de gelo").
2. **Mudança:** o Claude (ou quem estiver programando) cria um Pull Request com a alteração.
3. **Teste:** em cada Pull Request aparece um comentário com o **link de prévia**, por exemplo
   `https://giovannitorres0.github.io/hordew/pr-preview/pr-3/`. Abra, jogue e veja se ficou bom.
   O link leva 1 ou 2 minutos para ficar pronto depois de cada mudança.
4. **Aprovação:** qualquer pessoa do grupo pode aprovar (botão **Review changes → Approve**) e depois **Merge**.
   Ao fazer o merge, a versão oficial em https://giovannitorres0.github.io/hordew/ é atualizada sozinha.

Dica: para jogar sem cache depois de uma atualização, recarregue com Ctrl+F5.
